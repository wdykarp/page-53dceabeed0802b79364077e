01

订阅式交付

服务以订阅为单位进行购买与续费，订阅期内可用流量、设备数与节点池按所选档位确定。

每份订阅对应唯一的接入链接与密钥，凭据仅在用户客户端与服务器之间完成校验，不经过第三方。

节点分级

节点按用途分为浏览节点、流媒体节点与专线节点三类，对应不同档位的可用范围。

03 · 使用说明

从下单到连接的流程

以下流程按时间顺序展开。用户自备客户端，订阅链接需导入客户端后方可建立通道连接。凌云不内置客户端分发。

  1. 选择档位。依据每月预估流量与同时在线设备数，从基础版、旗舰版、团队版中选择合适档位。旗舰版为多数个人用户的推荐档位。
  2. 完成支付。支持按月或按年支付，按年支付在价格上享有一次性折扣。支付完成后，订阅关系立即在用户中心生效。
  3. 获取订阅链接。在用户中心复制对应的订阅地址，订阅地址为一次性导出，包含密钥信息，请妥善保管。
  4. 导入客户端。在自备客户端的订阅设置项中粘贴链接，由客户端拉取节点配置并完成握手校验。
  5. 选择节点。根据用途选择浏览节点、流媒体节点或专线节点。不同节点适合不同业务场景，跨档位节点不可越权使用。
  6. 续费与降级。订阅到期前可选择续费或降级，降级将在当前周期结束后的下一自然月生效。

节点分类与适用场景

浏览节点面向网页、邮件与日常应用，对连接稳定性要求高；流媒体节点面向视频与音频平台，需具备原生地区解析能力；专线节点面向对延迟敏感的场景，例如多人在线协作与远程会议。

三类节点的可用范围随订阅档位变化，团队版开放 VIP 专属高带宽节点，旗舰版开放全节点原生流媒体解锁。

流量计量与重置

流量按自然月计量，自每月一日零时起算，至月末最后一日二十四时止。期间内上传与下载流量合并计入配额，配额不可跨月结转。

达到月流量上限后，订阅仍保持有效，但通道进入限速状态，下一自然月自动恢复。旗舰版与团队版用户可申请按次临时扩容。

04 · 客户端接入

客户端与配置说明

凌云不内置客户端分发。用户需自行准备支持标准订阅协议的开源客户端，并在客户端中导入从用户中心获取的订阅链接。

订阅协议

订阅链接采用通用协议封装，可被多数主流开源客户端解析。链接中包含节点列表与密钥信息，请视为登录凭据保管。

客户端类型

桌面端、移动端与命令行端均可接入。客户端的选择属于用户侧的安装与配置行为，与凌云服务条款无直接关联。

多设备登录

同时在线的设备数受档位限制。超出并发上限时，最早建立的连接将被服务器端断开，请按需调整设备数量。

05 · 常见问题

按主题归类的 FAQ

以下问答按订阅、计费、节点、客户端与安全五个主题分组。所有答复均以本页规格为准，与本页不一致的口头承诺不具备效力。

订阅 / Subscription

凌云是 VPN 吗？
凌云是一项网络通道订阅服务，并非某一款具体客户端，也不内置客户端分发。订阅生效后，用户获得一组节点路由配置与接入凭据，用于在自备客户端中建立通道连接。
三档订阅之间如何切换？
用户中心提供升档与降档操作。升档在支付完成后立即生效，未消耗的月流量按差价折算；降档在当前计费周期结束后的下一自然月生效，期间仍按原档位提供服务。
可以多人共用一个订阅吗？
同一账号在同一时段可保持的客户端连接数即为并发上限。基础版 3 台、旗舰版 5 台、团队版 20 台。共享时请合理分配并发数，超出部分会被服务器端断开。

计费 / Billing

按月与按年支付的差价是多少？
基础版按月 ¥15、按年 ¥150；旗舰版按月 ¥35、按年 ¥350；团队版按月 ¥85、按年 ¥850。按年支付相当于十个月费用，为一次性折扣，不按月分摊返还。
未用尽的流量可以结转下个月吗？
不可以。月流量按自然月计量，未用尽部分不结转也不退款，达到上限后进入限速状态，下一自然月自动恢复。
是否支持退款？
订阅一经生效，因服务已消耗的流量与节点资源不予退款。如遇服务不可用超过连续七十二小时，可凭工单记录申请按未使用天数比例折算补偿，具体由客服工单裁定。

节点 / Nodes

三档订阅分别可以使用哪些节点？
基础版可使用普通线路节点池；旗舰版开放全节点原生流媒体解锁与 IPLC 专线节点；团队版在旗舰版基础上追加 VIP 专属高带宽节点，并支持企业定制路由。
节点速度不理想怎么办？
速度受本地网络、客户端设置与节点负载三方面影响。建议依次排查本地带宽上限、客户端协议与路由设置，再切换至负载较低的节点。团队版用户可联系专属客户经理协助诊断。
节点列表会定期更新吗？
会。节点新增、下线与维护信息通过用户中心公告提前七十二小时通知。订阅链接在更新后会自动重新拉取节点列表，无需手动操作。

客户端 / Clients

凌云提供客户端下载吗？
不提供。凌云不内置客户端分发，请使用支持标准订阅协议的开源客户端，并在客户端中粘贴从用户中心复制的订阅链接。客户端的安装、配置与升级均由用户自行完成。
订阅链接泄露怎么办？
请立即在用户中心重置密钥。重置后旧订阅链接即刻失效，需在客户端中重新导入新的链接。密钥重置操作可由用户自行完成，不计入工单配额。
如何在多设备之间同步配置？
建议在每台设备的客户端中使用同一订阅链接，由客户端自动同步节点列表。需要独立管理设备时，可为不同设备分别建立本地配置，互不影响。

安全 / Security

凌云会留存访问日志吗？
凌云服务器不读取客户端侧日志，也不在服务端留存用户的访问内容。服务器仅保留订阅关系与必要的计费记录，用于完成订阅管理与异常排查。
订阅链接是否应当加密保存？
建议将订阅链接视为登录凭据妥善保存，避免在公开渠道张贴。可在用户中心随时重置链接，重置后旧链接立即失效。
遇到连接异常如何反馈？
请在用户中心提交工单，并附上客户端版本、节点标识与异常发生的时间窗口。旗舰版与团队版用户享有优先工单响应，按提交顺序处理。
